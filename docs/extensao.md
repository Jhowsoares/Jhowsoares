# Projeto de Extensão — Sistema de Apoio para Casa de Repouso

Projeto acadêmico com impacto social, desenvolvido em parceria com a instituição **Morada do Saber** (Taboão da Serra - SP).

---

## Objetivo

Desenvolver uma solução digital para otimizar o cuidado a idosos, substituindo processos manuais (post-its, planilhas, ligações) por um sistema centralizado e automatizado.

---

## Etapas

| Fase | Atividades |
|------|-----------|
| **Pesquisa de campo** | Visitas presenciais · Identificação de dores reais · Entrevistas com cuidadores e enfermeiros |
| **Levantamento de requisitos** | Mapeamento de fluxos de trabalho · Priorização com stakeholders |
| **Prototipação** | Desenvolvimento de telas no Figma · Jornada do usuário · Refinamento de UX |
| **Desenvolvimento** | Arquitetura do sistema web · Cadastro de pacientes · Lembretes automatizados |

---

## Problemas identificados

- Lembretes manuais em post-its
- Ausência de alertas para medicamentos
- Dificuldade em rastrear tarefas pendentes
- Retrabalho administrativo

---

## Impacto social

| Resultado | Descrição |
|-----------|-----------|
| Redução de falhas | Menos esquecimentos de tarefas e medicamentos |
| Organização | Centralização de informações de pacientes |
| Rastreabilidade | Histórico de cuidados e ocorrências |
| Eficiência | Menos retrabalho para os cuidadores |
